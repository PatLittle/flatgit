Usage guide

View GitHub files without cloning a repository.

Paste a public GitHub repository, file, or Gist URL above. Full view adds repository and branch navigation; minimal view keeps the focus on the linked file. FlatGit runs entirely in your browser and does not require a sign-in.

Repository and file tools

  • Browse public repositories, branches, folders, files, and multi-file Gists.
  • Expand folders lazily, copy the viewer link, or open the raw file and its GitHub page.
  • See file size, detected type, branch, and last-modified date.
  • Use Full view for navigation or Minimal view for a clean, shareable preview.

Interactive tables

CSV, TSV, JSON records, SQLite results, and Parquet rows use the table viewer. Search all columns, filter individual columns, sort, resize or reorder columns, choose visible columns, change page size, jump to a page, and export the filtered visible data as CSV.

Query SQLite files

Select a table or view, edit the generated query, then choose Run query. FlatGit accepts read-only SELECT, WITH, PRAGMA, and EXPLAIN statements.

-- Preview 25 rows
SELECT * FROM "table_name" LIMIT 25;

-- Show the next 25 rows
SELECT * FROM "table_name" LIMIT 25 OFFSET 25;

-- Count every row
SELECT COUNT(*) AS total_rows FROM "table_name";

-- Count records by a category
SELECT "category", COUNT(*) AS records
FROM "table_name"
GROUP BY "category"
ORDER BY records DESC
LIMIT 20;

Use double quotes around table or column names containing spaces. Press Ctrl/Cmd + Enter to run the query.

Markdown display modes

  • Rendered: formatted GitHub-Flavoured Markdown with safe HTML, images, links, tables, badges, and Mermaid diagrams.
  • Source: the original Markdown text.
  • Split: source and rendered output side by side.

History and comparison

Choose History on a repository file to load up to 100 commits that touched its path. Select older and newer commits to see GitHub’s line patch, commit messages, dates, short SHAs, and addition/deletion totals. Gists and binary files may not provide a comparable text patch.

Theme and shortcuts

The ◐ control—or T—switches between light and dark themes and remembers the choice in this browser. Choose ? for all keyboard shortcuts.
